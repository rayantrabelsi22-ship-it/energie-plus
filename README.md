# Énergie+ — le hub

L'application de bureau d'Énergie+ : une page qui regroupe les outils de l'entreprise (demandes du formulaire, tableau de suivi…).

- Adresse : https://rayantrabelsi22-ship-it.github.io/energie-plus/
- Pour l'installer sur un PC : ouvrir l'adresse dans Chrome ou Edge, puis cliquer sur l'icône « Installer » dans la barre d'adresse.
- Les tableaux restent dans Google Sheets : cette page ne contient que des liens, aucun mot de passe ni donnée client.
- Pour ajouter un bouton : copier un bloc `<a class="carte">` dans `index.html`.
